# My Finance
Projeto simples de controle financeiro pessoal, desenvolvido com o foco em praticar o uso de API. Permite cadastrar, editar e excluir transações (crédito e débito), além de exibir o saldo atual.

## Funcionalidade da aplicação
- Adicionar nova transação (nome e valor).
- Editar uma transação existente.
- Excluir uma transação.
- Calcular e exibir o saldo total.
- Integração com API fake local (JSON Server).

## Tecnologias utilizadas na aplicação
- HTML
- CSS
- JavaScript
- JSON Server (para simular uma API REST)
